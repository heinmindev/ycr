# Discovery Workflow

Do not write production code.

1. Inspect requirements and available authoritative sources.
2. Separate facts from assumptions.
3. Identify actors and workflows.
4. Extract domain concepts.
5. Identify bounded contexts.
6. Propose architecture.
7. Identify data and integration requirements.
8. Create open questions.
9. Create ADRs for material architecture decisions.
10. Produce a review package.
11. Wait for human approval.

Output must include:
- System specification
- Functional requirements
- NFRs
- Domain model
- Architecture
- Database proposal
- API proposal
- Security model
- Test strategy
- Open questions
